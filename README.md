# 3D Skull Puzzle

An interactive anatomy puzzle for exploring the human skull. Observe, rotate, and assemble individual bones to learn their names and positions.

## Features

- 13 interactive skull pieces with Chinese names and descriptions
- Placement hints and automatic snapping
- Progress tracking and completion timer
- Classical anatomy classroom panorama
- Brown and gold interface
- Mouse and touch controls
- Different colors for unplaced, selected, and completed pieces

## How to Play

1. Click “開始拼圖” (Start Puzzle).
2. Select a bone to view its name and description.
3. Drag it toward the matching transparent outline.
4. Release it near the correct position to snap it into place.
5. Assemble all 13 pieces to complete the puzzle.

Drag an empty area to rotate the view. Use the mouse wheel or a two-finger gesture to zoom.

## Getting Started

Download the HTML file and open it in the latest version of Chrome or Edge.

All models, background images, and application code are embedded in a single HTML file. No installation or local server is required, and the puzzle works offline.

## Interface Language

The current game interface and bone descriptions are in Traditional Chinese.
